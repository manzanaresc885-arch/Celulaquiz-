# CélulaQuiz 🧬🔬

> **Autores:** Carlos y Deiber de CélulaQuiz

Un juego educativo, interactivo y divertido sobre biología celular, orgánulos y funciones celulares. Diseñado con una interfaz moderna y oscura (modo oscuro/cyber-bio), efectos de sonido, múltiples modos de juego, desafíos interactivos, modo tipo Kahoot multijugador con código PIN de 4 dígitos, niveles de dificultad, cazador de orgánulos y enciclopedia visual interactiva.

---

## 🚀 Características Principales

- 🎮 **Múltiples Modos de Juego:**
  - **Quiz Clásico:** Preguntas con tiempo límite, retroalimentación instantánea y frases de motivación si fallas.
  - **Modo Kahoot:** Sala de juego multijugador con código PIN de 4 dígitos, personalizable (tiempo, dificultad, número de preguntas) y podio en tiempo real.
  - **Cazador de Orgánulos:** Identifica y haz clic en los orgánulos sobre un diagrama celular interactivo.
  - **Verdadero o Falso:** Ronda rápida para poner a prueba tus reflejos y conocimientos biológicos.
  - **Modo Supervivencia:** Responde correctamente para mantener con vida a tu célula.
  - **Modo Duelo 1 vs 1:** Pantalla compartida interactiva para dos jugadores en un mismo dispositivo.
  - **Enciclopedia Celular:** Explora partes celulares (mitocondria, núcleo, ribosomas, cloroplastos, etc.) con modelos interactivos y explicaciones científicas amenas.
- ⚙️ **Altamente Personalizable:** Ajusta tu nombre de científico, nivel de dificultad (Fácil, Medio, Difícil, Mixto), cantidad de preguntas y tiempo por pregunta.
- 📱 **100% Adaptable para Móviles y Computadoras:** Desplazamiento táctil fluido y animaciones optimizadas.
- 🏆 **Sistema de Logros y Rachas:** Rachas de aciertos con mensajes de ánimo al fallar para nunca rendirse.

## 🛠️ Instalación y Ejecución Local

Para ejecutar CélulaQuiz en tu computadora localmente:

1. **Requisitos Previos:**
   - Tener instalado [Node.js](https://nodejs.org/) (versión 18 o superior).
   - Administrador de paquetes `npm` (incluido con Node.js).

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   Abre tu navegador en `http://localhost:3000` (o el puerto indicado en la terminal).

4. **Compilar para producción:**
   ```bash
   npm run build
   ```

## 🐙 Cómo subir este proyecto a GitHub

Si deseas subir este proyecto a tu propio repositorio de GitHub:

1. **Descomprime el archivo ZIP** en una carpeta de tu preferencia en tu computadora.
2. Abre la terminal o consola de comandos dentro de esa carpeta descomprimida.
3. Ejecuta los siguientes comandos:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Proyecto CélulaQuiz por Carlos y Deiber"
   git branch -M main
   ```
4. Crea un nuevo repositorio en [GitHub.com](https://github.com/new).
5. Copia la URL de tu repositorio de GitHub y vincula tu repositorio local:
   ```bash
   git remote add origin https://github.com/TU_USUARIO/TU_REPOSITORIO.git
   git push -u origin main
   ```
¡Y listo! Tu código estará publicado en GitHub.
